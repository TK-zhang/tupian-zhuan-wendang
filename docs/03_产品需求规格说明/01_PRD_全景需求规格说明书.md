# 产品需求规格说明书 (PRD) - 全景业务与功能规格

## 1. 业务背景与系统目标
本系统面向**“拍摄照片集、会议白板、操作录像、纸质档案扫描件”**等多种散乱视觉素材，通过多模态 AI 与计算机视觉，实现全自动化清洗、纠偏、重组织，输出具备丰富大纲层级、高保真组件（表格/公式/矢量图）及网状超链接的企业级文档群。

### 1.1 目标客户分级与交付形态矩阵
根据合规边界与运行环境要求，系统设计必须严格支撑以下三类客户交付矩阵：
1. **Tier 1: B端政企客户（涉密/物理隔离/离线部署）**：
   - **交付架构**：软硬件一体机（Turnkey Appliance）+ 本地 100% 离线交付；
   - **工程服务**：提供推理加速卡（国产算力卡/RTX 4090/L40S）代采、现场工程部署加固与验收、离线维保；
   - **安全要求**：无网络连接、内存自销毁、防逆向、硬件加密狗/硬件指纹 License。
2. **Tier 2: B端通用商业客户（可线上/云端/专有云部署）**：
   - **交付架构**：多租户 SaaS 云服务 / 专有云 VPC 集群部署；
   - **工程服务**：企业 SSO 对接、多项目与权限隔离管理、RESTful/gRPC API 高并发调用支持；
   - **核心价值**：外包交付提效、咨询尽调知识沉淀、团队文档协同。
3. **Tier 3: C端个人用户（跨平台单机客户端）**：
   - **交付架构**：Windows / macOS 原生单机应用；
   - **算力适配**：本地轻量级模型离线推理（具备显卡设备）或用户自定义云端 API Key；
   - **核心价值**：学术科研、考研学习、Obsidian 本地双链知识库无感构建。

## 2. 功能需求全景矩阵 (Functional Requirements)

### 2.1 模块一：多模态多源摄入与预处理流水线
- **FR-101 多形态数据源支持**：
  - 图片格式：PNG, JPG, JPEG, WEBP, HEIC 等批量导入。
  - 视频/录屏格式：MP4, MKV, MOV 等连续操作或演示视频。
- **FR-102 视频关键帧智能提取与去重（Video-to-Keyframes）**：
  - 基于场景切换检测（Scene Cut）与感知哈希（pHash / SSIM），自动过滤过渡模糊帧与鼠标指针移动冗余帧，仅提取最高清静止帧。
- **FR-103 视听双模态融合（Audio-Visual Fusion）**：
  - 提取解说音频轨，经 ASR 转录生成带时间戳字幕，与对应画面进行时空对齐，补齐演讲者的背景意图。
- **FR-104 图像几何校正与画质增强**：
  - 透视变换拉平俯视图、自适应去反光、去屏幕摩尔纹、局部对比度增强。

---

### 2.2 模块二：AI 驱动的文档重组织引擎 (The Core Soul)
- **FR-201 散乱素材主题聚类（Clustering into Doc Cluster）**：
  - 面对一批可能混杂了多个主题的几十张照片，AI 全局通读，按业务边界自动切分为**“文档群”**（如《架构设计》、《接口规范》、《数据字典》）。
- **FR-202 动态专业大纲重构（Dynamic Outline Generation）**：
  - 摆脱物理拍摄顺序的束缚，按照行业金标准重建逻辑树（`概述 -> 架构拓扑 -> 模块详解 -> 异常/FAQ`）。
- **FR-203 碎片内容路由与去重提炼（Content Routing & Synthesis）**：
  - 将多张截图中分散出现的同模块配置或参数，智能去重并融合成唯一的最新完整版本。

---

### 2.3 模块三：上下文智能纠偏与自愈系统 (Contextual Rectification)
- **FR-301 代码与语法树局部纠偏**：
  - 针对反光遮挡或拍摄模糊，结合 AST 词法规则与 LLM，自动修复被误读的代码/SQL/JSON 关键符号（如 `1O` -> `10`, `f0r` -> `for`）。
- **FR-302 集群级全局实体一致性对齐**：
  - 构建全文档群的全局专有名词与标识符字典，消歧前后拼写不一致。
- **FR-303 逻辑断裂与关键步骤缺失警示**：
  - 探测到时序跳跃（如只有步骤 1 和步骤 3）时，插入友好警示引用块（`> [!WARNING]`），拒绝模型幻觉。

---

### 2.4 模块四：超链接与知识网络构建 (Hyperlinks & Mesh)
- **FR-401 文档内精细化锚点**：正文中的“见第 2 节”、“如图 1 所示”自动转为精准跳转锚点。
- **FR-402 跨文档互联超链接**：文档群内跨文档引用自动转为相对路径链接。
- **FR-403 Obsidian 双链与全局关系拓扑图谱**：输出 `[[双链]]` 语法与可视化关系图谱数据。

### 2.6 模块六：应用安全、防破解与离线授权保护 (Security & Anti-Reverse Engineering)
- **FR-601 硬件指纹绑定与非对称离线授权 (Hardware Fingerprinting & Licensing)**：
  - 支持提取设备硬件指纹（主板 UUID + CPU 序列号 + 硬盘序列号），结合 RSA-4096 / Ed25519 非对称加密算法签发离线授权 License 文件；
  - 高涉密场景支持硬件加密狗（USB Dongle）物理授权验证，严禁单机授权跨机器复制。
- **FR-602 运行时完整性校验与防篡改 (Runtime Integrity & Anti-Tampering)**：
  - 启动时自动执行主程序二进制哈希校验，防止内存 Patch 与二进制 Hex 篡改破解；
  - 防时间回拨机制：记录加密的单调递增运行时钟状态，防止用户通过修改操作系统时间绕过许可证有效期。
- **FR-603 运行时防调试与防内存 Dump (Anti-Debugging & Memory Protection)**：
  - 检测动态调试器附加（如 x64dbg, IDA Pro, Frida, CheatEngine），检测到调试行为时立即清空敏感内存并安全退出；
  - 敏感模型配置、Prompt 管道参数在完成单次调用后，立即执行内存置零擦除（Memory Zeroing），防止通过内存 Dump 获取私有模型资产。
- **FR-604 敏感临时数据生命周期安全销毁 (Secure Data Sanitization)**：
  - 运算过程中产生的图像切片缓存、中间音频 WAV 缓存、临时 OCR 索引，默认存放在加密的虚拟内存盘或采用 AES-256 加密的临时 SQLite 中；
  - 文档交付导出完成后，系统强制调用 DoD 5220.22-M 标准擦除算法覆盖并销毁临时文件，防止在审计机房被取证软件恢复。

---

### 2.7 模块七：知识库混合索引、具身问答与自演进反哺系统 (Knowledge Base & Feedback Flywheel)
- **FR-701 多模态四路混合索引与毫秒级精准检索 (Hybrid Multi-modal Indexing)**：
  - 构建 SQLite FTS5 词法全文索引，实现代码、IP、数据库表字段、错误码的 100% 精确召回；
  - 集成离线密集向量索引（HNSW），支撑自然语言模糊语义检索；
  - 集成实体拓扑图谱索引，支撑跨文档多跳关联查询；
  - 维护字符级与图表级像素坐标倒排索引，单文档库百万级 Token 规模检索响应时间 < 50ms。
- **FR-702 具身可溯源专业问答助手 (Evidence-Grounded Q&A Assistant)**：
  - 严格基于重构文档库事实进行约束推理，禁止无依据推测；
  - 问答结果输出附带可交互双模态引用卡片：点击任意答案段落，自动弹出原始照片的高清截面与高亮黄色红框标注，实现免责级肉眼核对。
- **FR-703 交互反馈与底层重构自愈反哺机制 (The Closed-Loop Feedback Flywheel)**：
  - **问答纠错级联自愈**：用户在问答交互中对错误参数的纠偏，自动生成增量补丁（Delta Patch），反向更新底层 AST 语法树并同步校准全局实体词典；
  - **提问模式反哺大纲优化**：分析高频追问与低置信度盲区，自动触发重组织引擎为高频关键主题增设独立章节或对比表格；
  - **增量素材秒级挂载**：后续补充拍摄的新图片/新录像通过局部特征比对执行增量索引更新，避免全量重新计算。

## 3. 非功能性需求安全指标 (Security NFRs)
1. **代码混淆与防逆向等级**：
   - 核心 Python 逻辑必须通过 Cython / Nuitka 编译为机器码二进制文件（`.pyd` / `.so`），排除使用明文 `.py` 或普通 `pyc` 字节码交付；
   - 外部调用接口与字符串常量采用动态混淆加密存储。
2. **离线隔离运行可靠性**：
   - 授权校验模块 100% 本地运算，全流程无任何心跳外联或网络探测行为，完全符合断网涉密机房合规审计要求。
