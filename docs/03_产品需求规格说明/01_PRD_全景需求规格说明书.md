# 产品需求规格说明书 (PRD) - 全景业务与功能规格

## 1. 业务背景、战略收敛与客群切入矩阵

本系统面向**无现成电子原件场景下的多源有损视觉素材**（带摩尔纹/反光的屏幕翻拍、现场工程巡检盲拍照片集、Citrix/VDI 或遗留系统操作录屏、伴随语音解说），通过几何逆变换坐标守恒、跨时序冲突消歧、编译期 AST 语法自愈与母版排版求解，输出像素级可溯源、零排版错乱的企业级交付文档群（Word `.docx`、PPT `.pptx`、矢量 PDF、Markdown）。

### 1.1 目标客户分级与分阶段切入矩阵 (GTM Sequencing)
为避免早期研发战线过宽，系统在底层保持跨形态无头架构兼容的同时，按采购周期与付费刚性执行严格的分阶段切入策略：

1. **第一优先级（Phase 1 PMF 核心突破口）：Tier 2 B端垂直交付与专业服务团队**
   - **目标客群**：IT 实施与软件外包驻场团队、工程检测与安全评估机构、会计师/律师事务所现场尽调团队；
   - **交付形态**：企业专有云（VPC 容器部署）/ 多租户 SaaS / 绑定硬件指纹的驻场单机专业版；
   - **核心价值**：2~4 周短决策周期，直接消除“百张现场照片/录屏整理与甲方严苛 `.docx` 母版排版耗时数小时”的高频人力成本。
2. **第二优先级（Phase 2 利润支柱）：Tier 1 B端政企与涉密物理隔离客户**
   - **目标客群**：党政机关、军工院所、能源工控、金融机构（授权遗留系统信创迁移逆向建档、隔离机房巡检归档）；
   - **交付形态**：软硬件一体机（Turnkey Appliance）+ 推理加速卡（昇腾等国产卡 / RTX 4090 / L40S）代采集成 + 现场加固验收；
   - **安全要求**：100% 物理断网运行、RAM Disk 零磁盘残留、防调试机器码固化、Ed25519 硬件指纹/加密狗离线验签。
3. **第三优先级（PLG 口碑与样本漏斗）：Tier 3 C端个人技术与科研用户**
   - **目标客群**：高校科研人员、独立顾问、Obsidian 深度用户；
   - **交付形态**：Windows / macOS 跨平台桌面客户端（强制采用用户自备 API Key 或本地独显推理，平台零算力补贴成本，不投入付费买量）。

## 2. 功能需求全景矩阵与研发优先级 (MoSCoW Matrix)

> [!IMPORTANT]
> **研发范围收敛约束**：
> - **核心主航道（P0 / P1）**：聚焦模块一至模块五（退化视觉预处理与逆坐标守恒、跨时序消歧重组、编译期纠偏与待复核工单、导出前 Click-to-Source 核验工作台、甲方母版级 `.docx`/`.pptx` 确定性编译）；对于常规单页版面分割等成熟环节优先集成开源算子（如 MinerU / Docling / PP-Structure）。
> - **安全准入底座（P1）**：模块六面向离线商业分发与政企一体机交付提供二进制保护与物理擦除。
> - **远期增值扩展（P2 / Post-PMF）**：模块七（四路混合检索与问答反哺知识库）仅在底层 `DocAST` 与存储契约层保留前置兼容，排期置于核心编译交付闭环跑通之后，**严禁早期抽调核心资源与通用 PDF 知识库厂商（如 ChatDOC、RAGFlow、腾讯 ima）进行同质化正面竞争**。

### 2.1 模块一：多模态摄入、退化修复与逆坐标守恒流水线 `【优先级: P0】`
- **FR-101 多源非侵入数据摄入**：
  - 静态图像批量摄入：PNG, JPG, JPEG, WEBP, HEIC, TIFF（只读就地引用，严禁全量复制膨胀缓存）；
  - 连续录屏/演示视频摄入：MP4, MKV, MOV（适配外部采集卡或本地录制 Citrix/VDI 窗口视频）。
- **FR-102 视频关键帧提取与动态冗余剔除（Video-to-Keyframes）**：
  - 基于场景切换检测（Scene Cut）结合差分哈希（dHash）与结构相似度（SSIM），自动滤除过渡模糊帧与单纯鼠标指针移动帧，按拉普拉斯方差（Laplacian Variance）保留最清晰静态帧。
- **FR-103 视听双模态时空对齐（Audio-Visual Alignment）**：
  - 分离音轨并经离线 ASR（Whisper / SenseVoice）生成带词句级时间戳文本，与对应时间窗画面帧精确绑定。
- **FR-104 退化屏摄增强与亚像素逆变换坐标守恒**：
  - 针对斜拍透视畸变执行单应性矩阵（Homography $H$）拉平，针对屏幕像素干涉执行频域去摩尔纹与 CLAHE 局部去反光；
  - 持久化保存逆矩阵 $H^{-1}$，确保后续识别出的任意字符与单元格坐标可亚像素级反投回原始未变形底片（IoU $\ge 0.90$）。

### 2.2 模块二：跨时序状态消歧与文档群重组织引擎 `【优先级: P0】`
- **FR-201 散乱多主题素材业务分卷（Clustering into Doc Cluster）**：
  - 对乱序混杂的数十至上百张图片与视频关键帧提取语义特征与核心实体，按业务内聚度自动切分为独立文档卷（如《系统架构说明》《数据字典规范》《接口规约》《巡检记录》）。
- **FR-202 长视图滚动重叠拼接（Scroll-Stitching Deduplication）**：
  - 针对长表格、长配置页或长代码分多次滚动拍摄的重叠照片，基于局部视觉特征与文本行滑动哈希对齐缝合为单一完整结构，剔除重复行并保留分段原图溯源映射。
- **FR-203 跨时序状态回退与覆盖消歧（Temporal State Resolution）**：
  - 在连续录屏或连拍序列中，识别同一界面面板的前后多次修改（如先配置报错、后回退重配），构建时序状态图，将最终有效配置归入正文主流程，将历史报错帧归入异常排查章节。
- **FR-204 行业模板约束的动态大纲重构（Constrained Outline Synthesis）**：
  - 脱离物理拍摄时间顺序，按选定行业交付物母版（如敏捷 PRD、架构决策记录 ADR、安全巡检报告、审计底稿）组织标准章节层级。

### 2.3 模块三：编译期语法自愈与人机仲裁系统 `【优先级: P0】`
- **FR-301 代码与结构化语法树编译期纠偏**：
  - 对屏摄提取的代码、SQL、JSON、YAML 强制调用静态语法解析器（Python `ast`、`SQLGlot`、`Tree-sitter`）校验；校验失败时结合跨图词法上下文修正易混字符（如 `0/O`、`1/l/I`）。
- **FR-302 集群级全局实体符号表对齐**：
  - 维护跨文档专有标识符（表名、服务名、IP 端口、设备编码）全局注册表，消除局部拍摄模糊造成的拼写分裂。
- **FR-303 音画冲突与低置信度非阻塞待复核队列（Review Queue）**：
  - 当识别置信度 $< 0.85$、存在操作步骤时序断层、或语音口述数值与屏幕实际显示参数冲突时，**严禁模型概率脑补**，后台不中断流水线，统一标记 `PENDING_REVIEW` 并归集至右侧待复核工单面板供人工一键仲裁。

### 2.4 模块四：导出前 Click-to-Source 核验与跨文档超链接网格 `【优先级: P1】`
- **FR-401 双模态像素级实时溯源核验（Click-to-Source Workbench）**：
  - 点击重构文档中的任意参数、代码行或表格单元格，右侧底片画布在 `120ms` 内定位至原始照片对应四点多边形区域并高亮显示，支撑签字交付前的快速免责复核。
- **FR-402 文档内原生书签与跨文档超链接注入**：
  - 正文显式引用（如“详见第 2.3 节”“参见表 1-2”）自动编译为 Word 原生 `Bookmark/Hyperlink` 或跨文档相对路径链接；Markdown 导出支持标准 Obsidian `[[双链]]` 语法。

### 2.6 模块六：应用防逆向、离线授权与涉密零残留保护 `【优先级: P1】`
- **FR-601 硬件指纹绑定与 Ed25519 非对称离线授权**：提取主板 UUID + CPU ID + 磁盘序列号组合哈希，纯本地数字签名验签，高涉密场景支持 USB 加密狗。
- **FR-602 运行时完整性校验与单调时钟防回拨**：校验二进制哈希防内存补丁，维护加密单调递增时钟防止篡改系统时间续期。
- **FR-603 反动态调试与敏感内存即时清零**：检测调试器挂载（x64dbg, IDA, Frida）安全退出，敏感中间数据调用后立即执行 `SecureZeroMemory` 置零。
- **FR-604 涉密零残留与 DoD 5220.22-M 安全销毁**：支持 `SECURITY_EPHEMERAL_MODE` 全内存虚拟盘（RAM Disk）流转；若产生临时落盘，采用 AES-256 加密并在导出后执行三次覆写擦除。

### 2.7 模块七：工程资产混合检索与增量反哺飞轮 `【优先级: P2 远期可选扩展】`
- **定位约束**：仅面向本系统重构产出的多卷工程资产提供配套核查与纠错回写，不作为独立通用知识库售卖。
- **FR-701 本地四路混合索引**：基于单文件 SQLite FTS5 + 轻量 HNSW 向量 + 实体关系三元组 + BBox 空间坐标构建离线检索，单库百万 Token 检索延迟 $< 50\text{ ms}$。
- **FR-702 强证据约束问答**：检索回答强制附带原始底片截面引用卡片。
- **FR-703 类 Git 版本化 AST 增量反哺**：问答或巡检复核中提交的参数勘误生成 RFC 6902 `AST Delta Patch`，经乐观并发锁校验后安全更新底层 `.docx`/Markdown 并支持一键回滚。

## 3. 非功能性指标与基准验收约束 (NFRs & Benchmark Gate)
1. **代码机器码固化**：核心编排、消歧与 OpenXML 编译逻辑通过 Cython / Nuitka 编译为原生二进制（`.pyd` / `.so`），剥离调试符号。
2. **离线与信创构建合规**：全栈依赖保持 ARM64 / LoongArch 纯源码可构建性，全流程零公网连接。
3. **竞品基准净增益准出**：每个主迭代版本必须在 100 组真实退化屏摄/巡检/VDI 录屏基准集上跑通与“开源解析器 + 通用 VLM 脚本”的盲测对比，确保在参数准确率、母版免返工率与人工核对耗时上具备可量化的统计净增益。
