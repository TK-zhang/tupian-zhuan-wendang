# 扩展迭代 PRD - Iteration 5：跨模态视频录屏切帧与音画对齐文档化

## 1. 迭代概述与交付目标

### 1.1 业务诉求
除散乱静态拍照外，企业在知识传承与老旧系统逆向改造中，存在大量**“长录屏、操作演示视频、系统巡检操作录像”**（时长通常在 10 ~ 60 分钟，格式为 MP4 / MKV / MOV）。
视频的本质是连续时间序列图像与连续语音轨的复合体。人工观看整理极其耗时，且逐帧截图会产生数以万计的无价值重复帧（如鼠标指针微小移动、无操作等待）。
Iteration 5 的核心使命是构建**“视频转高精操作规程（Video-to-SOP）端到端流水线”**：
通过场景切换感知（Scene Cut）过滤冗余静止帧，结合 Whisper 语音转录，将讲解人现场口述与操作界面进行微秒级时间戳对齐，全自动生成**“步骤分解 + 关键操作截图 + 语音意图阐释”**的标准化操作指南（SOP）。

### 1.2 阶段验收核心指标
1. **视频冗余帧过滤比**：1 小时连续操作视频，冗余帧过滤剔除率 $\ge 88\%$（最终提取有效关键步骤帧 $\le 120$ 张）；
2. **语音识别字错率 (CER)**：标准普通话与英文讲解转录 CER $\le 5\%$；
3. **音画时空对齐时差**：讲解人语音关键动作词与界面画面变化的时间戳偏差 $\le 0.5\text{s}$；
4. **SOP 步骤自动归纳完整率**：操作动作的“进入页面 -> 输入参数 -> 点击确认 -> 响应弹窗”四元组完整提取率 $\ge 90\%$。

## 2. 详细功能需求规格 (Functional Requirements)

### FR-501: 硬件加速场景切换切帧 (Hardware-Accelerated Scene Cut Detection)
- **处理逻辑**：
  - 调用 `FFmpeg` 底层 API（支持 NVDEC / QuickSync 硬件解码加速）；
  - 基于亮度直方图突变与像素残差（Pixel Delta），计算连续帧间的绝对差异；
  - 动态设定场景变化阈值（Scene Change Threshold $= 0.35$），精确捕捉界面切换、弹出对话框或页面滚动的物理起始时刻；
  - 输出候选关键帧集合（Candidate Keyframes）及绝对时间戳（`pts_time`）。

### FR-502: 鼠标指针位移过滤与感知哈希去重 (Perceptual Hash & SSIM Deduplication)
- **处理逻辑**：
  - 针对同一场景内的多张候选帧，执行结构相似性分析（SSIM）与差分感知哈希（dHash）；
  - **指针与光标抖动过滤**：若两帧画面除鼠标指针坐标发生微小位移外，其余有效内容区域相似度 $\ge 98.5\%$，则判定为用户停顿或读屏无意义帧，强制剔除；
  - 针对长表格或长表单的鼠标滚动，执行局部拼接（Stitching），融合成单张完整视窗截图。

### FR-503: Whisper 离线高精度音频转录 (Offline Whisper Audio Transcription)
- **处理逻辑**：
  - 从视频容器中无损分离出音频轨（WAV, 16kHz, 单声道）；
  - 调用本地离线 Whisper 模型（如 Whisper-Large-v3-Turbo 或量化版），生成逐字级/逐句级转录文本；
  - 记录每个转录片段的起始与结束时间戳：`[start_time, end_time, text]`；
  - 过滤“呃、啊、那个”等口癖语气助词，规整为书面自然语言。

### FR-504: 音画时空时序联合对齐 (Temporal-Spatial Audio-Visual Alignment)
- **处理逻辑**：
  - 将关键帧的时间戳序列与音频字幕的时间戳区间进行滑动窗口交叉互相关分析；
  - **语义绑定**：将讲解人所说的“点击右上角进入系统设置”与对应时刻截取出的系统设置高亮帧进行刚性对齐；
  - 自动在截图上根据鼠标点击热点（Click Hotspot）生成红圈标注。

### FR-505: 连续动作转标准化 SOP 规格生成 (Action-to-SOP Generator)
- **处理逻辑**：
  - 将对齐后的音画时序序列传入结构化归纳器；
  - 按照标准操作手册规约输出：
    - `步骤编号`：步骤 1, 步骤 2...
    - `操作目标`：简明概括本步骤行为（如“配置数据库连接池”）；
    - `界面截图`：包含操作热点标注的高清原图；
    - `详细说明`：由语音讲解与界面 OCR 参数融合而成的操作明细；
    - `输入参数对照表`：将画面中填写的表单字段自动整理为参数表格。

## 4. 边界场景与异常防御矩阵

| 边界场景 | 现象描述 | 确定性防御方案 |
| :--- | :--- | :--- |
| **纯静音或背景嘈杂** | 操作视频没有录制声音，或者现场噪声极大导致 Whisper 转录失败 | 降级机制：自动触发纯视觉变化流，根据界面表单焦点转移生成步骤描述，并在日志提示无音频输入 |
| **4K 60FPS 超高码率视频** | 单视频达 10GB 以上，全部加载会导致显存和内存崩溃 | 采用流式切片处理（Streaming Chunking）：按 3 分钟为一个分段进行流式解包与特征计算，处理完即释放内存 |
| **快速连续晃动拖拽** | 演示者频繁快速晃动窗口或乱晃鼠标 | 引入移动向量方差平滑过滤器，剔除高频振荡噪点，只在窗口停止移动并静止超过 0.5s 时取样 |
