# 确定性技术壁垒与合规准入条件分析 (Defensibility & Compliance Barriers)

## 1. 算法能力与确定性工程的边界划分

在大模型应用架构中，需将“概率性生成能力”与“确定性软件工程能力”进行解耦评估：

```text
+-------------------------------------------------------------+
| 概率性推理 (大模型解决)                                        |
| - 非结构化视觉文本提取 (OCR)                                    |
| - 语义大纲拓扑归纳                                            |
| - 自然语言摘要与实体提取                                       |
+-------------------------------------------------------------+
                              vs
+-------------------------------------------------------------+
| 确定性工程 (传统算法与系统软件解决)                             |
| - 图像局部特征微分检测与子像素坐标回归                         |
| - 代码抽象语法树（AST）编译校验与括号/类型闭合自愈               |
| - 表格跨页行列拓扑对齐与合并单元格计算                         |
| - 微软 OpenXML 二进制架构组装                                |
| - 双模态像素级对应矩阵映射 (Pixel-to-Text Mapping Matrix)      |
+-------------------------------------------------------------+
```

## 2. 核心技术壁垒的理性剖析

### 2.1 双模态像素级逆向索引与置信度热力矩阵 (Bimodal Coordinate Mapping)
1. **技术实现**：
   - 提取过程中，系统保留每个 token 及每个视觉结构块（图表、单元格、公式）在原始图像上的归一化边界框坐标 `[ymin, xmin, ymax, xmax]` 与原始帧时间戳 `t`。
   - 构建双向映射查找表（Bi-directional Lookup Table）：
     $$\text{Lookup}(DocOffset) \to (ImageID, BoundingBox)$$
2. **应用价值**：
   - 解决概率模型的幻觉免责问题。在严肃交付场景中，提供证据溯源机制，用户可通过点击文档任意元素调取原始物理像素，降低人工校对时间复杂度至 $O(K)$（$K$ 为低置信度标记数量）。

### 2.2 跨页几何拓扑与 AST 混合纠偏 (Hybrid Rectification Pipeline)
1. **代码与结构化数据校验**：
   - 多模态模型直接输出的代码块必须通过静态分析器（如 Python `ast.parse`、SQLGlot、Tree-sitter）进行编译期校验。
   - 校验失败时，基于词法状态机执行局部确定性修正，消除字符混淆（如将误识的 `O/0`、`I/l/1` 依据上下文符号表还原）。
2. **表格跨页缝合几何计算**：
   - 结合图像边缘连续性与列宽投影直方图，计算跨页表格列宽分布的皮尔逊相关系数：
     $$r = \frac{\sum (w_{1,i} - \bar{w}_1)(w_{2,i} - \bar{w}_2)}{\sqrt{\sum (w_{1,i} - \bar{w}_1)^2 \sum (w_{2,i} - \bar{w}_2)^2}}$$
   - 当 $r > 0.85$ 且表头特征缺失时，判定为连续表格并执行结构化合并。

## 3. 合规准入与物理隔离壁垒 (Compliance & Air-Gapped Constraints)

在高客单价行业（金融、军工、司法鉴定、审计），技术选型受制于法律法规与信息安全标准，形成天然准入屏障：

1. **数据出境与外网通信限制**：
   - 符合《中华人民共和国数据安全法》、《网络安全等级保护基本要求（等保 2.0 三级）》及 GDPR 等规范。
   - 目标客户内网环境通常实施**网络物理隔离（Air-Gapped Network）**或**虚拟桌面基础架构（VDI）无剪贴板/无外网策略**。
2. **离线单机部署规范**：
   - 软件系统必须打包为无外网依赖的独立运行包（Standalone Binary / Container Image）。
   - 运行环境受限于终端硬件配置（典型为 8GB~16GB 内存无独显办公机，或单张消费级显卡工作站）。
   - 要求模型端推理采用 4-bit / 8-bit 量化（AWQ / GGUF），推理框架需适配低算力设备并保持推理吞吐量 $\ge 15\text{ tokens/s}$。
