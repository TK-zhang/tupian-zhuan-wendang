# 确定性技术壁垒与合规准入条件分析 (Defensibility & Compliance Barriers)

## 1. 浅层非壁垒能力与深层复合壁垒的客观剥离

在 2025—2026 年多模态大模型（如 Qwen3-VL、Gemini 系列）与开源版面解析库（MinerU 2.5、Docling、PP-Structure）快速演进的背景下，必须严格区分**“已被开源生态解决的常规功能（不构成壁垒）”**与**“大模型概率生成机制无法自发解决的复合系统工程壁垒”**：

| 技术层次分类 | 具体技术项 | 壁垒强度评估 | 工程实施决策 |
| :--- | :--- | :--- | :--- |
| **浅层能力（非核心壁垒）** | 单页常规版面目标检测、多栏 XY-Cut 阅读序恢复、清晰规整跨页表格合并 | **低**（MinerU 2.5、Docling、PaddleOCR-VL 已开源高质量实现） | **直接集成适配标准开源算子**，严禁耗费早期工时从零重造检测器轮子。 |
| **浅层能力（非核心壁垒）** | 单次长上下文主题总结与基础目录树生成 | **低**（依托百万 Token 窗口 VLM 通过 Prompt 即可快速复现） | 仅作为流水线中间语义归纳步骤，不作为独立商业卖点。 |
| **必要防护（交付准入条件）** | Cython/Nuitka 二进制编译加固、Ed25519 硬件指纹离线验签 | **中低**（成熟商业软件通用防护工程） | 作为离线商业授权防拷贝底线标配，不视为核心市场竞争壁垒。 |
| **★ 核心壁垒一（几何+词法耦合）** | **退化屏摄图像逆单应性矩阵（$H^{-1}$）亚像素坐标守恒 + 编译期 AST 确定性纠偏** | **高**（端到端大模型重绘或纯文本生成会彻底破坏几何逆映射与严格语法约束） | **核心自研**：构建频域去摩尔纹、透视校正、跨图符号表对齐与原图亚像素反向投影闭环。 |
| **★ 核心壁垒二（跨时空状态机）** | **多源异构碎片滚动拼接（Scroll-Stitching）与跨时序状态回退/冲突消歧引擎** | **高**（通用 VLM 一次性吞入多帧极易将作废错误配置与最终生效状态混同输出） | **核心自研**：结合局部视觉特征匹配与时序有向状态图，识别状态覆盖并显式标记音画冲突。 |
| **★ 核心壁垒三（受控排版求解）** | **复杂 DocAST 到企业母版级 OpenXML（`.docx`/`.pptx`）的向下兼容布局求解器** | **中高**（嵌套合并表格、版心自适应高清裁切图、书签引用在旧版 Office/WPS 极易崩坏） | **核心自研**：绕开有损 Pandoc 转换，构建基于 Transitional XML 契约的确定性排版编译器。 |
| **★ 核心壁垒四（离线异构优化）** | **物理断网与国产信创硬件（ARM64/LoongArch + 国产 NPU）低算力精度-吞吐协同** | **中高**（无法调用云端超大模型，需靠轻量 CV + 4/8-bit 量化小模型 + 规则校验逼近云端精度） | **核心自研**：构建 UDAL 硬件抽象层与纯源码静态容器交付链，建立政企准入壁垒。 |

## 2. 四大核心复合工程壁垒的技术机理剖析

### 2.1 退化屏摄下的几何逆变换坐标守恒与编译期 AST 混合纠偏
1. **亚像素逆投影数学守恒（Sub-pixel Inverse Homography Provenance）**：
   - 现场斜拍屏幕或纸质台账需先经透视单应性矩阵 $H \in \mathbb{R}^{3 \times 3}$ 校正为正视图 $I' = \mathcal{W}(I, H)$，并执行频域陷波滤波抑制像素干涉摩尔纹。
   - 尽管文本与表格提取在正视图 $I'$ 的局部切片坐标系中进行，但所有提取出的字符 Token 与单元格顶点 $(x', y')$ 必须通过精确逆矩阵 $H^{-1}$ 齐次变换反投回**原始未变形底片坐标系**：
     $$\begin{bmatrix} \tilde{x} \\ \tilde{y} \\ \tilde{w} \end{bmatrix} = H^{-1} \begin{bmatrix} x' + \Delta x_{\text{crop}} \\ y' + \Delta y_{\text{crop}} \\ 1 \end{bmatrix}, \quad (x_{\text{orig}}, y_{\text{orig}}) = \left(\frac{\tilde{x}}{\tilde{w}}, \frac{\tilde{y}}{\tilde{w}}\right)$$
   - **不可替代性**：相较于市面上仅能在平整原生 PDF 上画矩形框的常规溯源工具（如常规 PDF 问答系统），本机制实现了对**任意角度倾斜翻拍、局部裁剪及多级拼接后原始物理底片**的四点多边形精准溯源，将人工复核复杂度从全篇通读 $O(N)$ 压缩至仅核验低置信度节点 $O(K)$（通常 $K \ll 0.05N$）。
2. **编译期 AST 与全局符号表确定性自愈**：
   - 多模态模型识别屏摄代码、SQL、配置文件或接口报文后，强制通过静态语法解析器（Python `ast`、`SQLGlot`、`Tree-sitter`）执行编译期语法校验；
   - 若因反光或摩尔纹产生语法断裂或字符混淆（如 `0/O`、`1/l/I`、`:`/`;`），结合**跨文档全局标识符符号表（Global Symbol Table）**与编辑距离约束执行确定性替换；无法唯一消歧时（置信度 $< 0.85$）强制挂入非阻塞待复核工单（Review Queue），严禁概率脑补。

### 2.2 跨时序、多视角异构碎片的状态消歧引擎
真实工程采集并非干净的静态页面，而是包含大量冗余与前后矛盾的动态过程：
1. **长视图滚动重叠拼接（Scroll-Stitching Deduplication）**：针对长表格或长配置文件分 3~5 张连续滚动拍摄的照片，利用局部特征点匹配（ORB/SIFT + RANSAC）与文本行哈希滑动窗口检测重叠区域，无损缝合为单一完整表格并保留各行对应的原图分片溯源链。
2. **时序操作回退与状态覆盖推导（Temporal State Resolution）**：在 30 分钟系统配置录屏中，操作者常在第 $t_1$ 时刻输入错误参数触发报错，随后在第 $t_2$（$t_2 > t_1$）时刻修改为正确参数。系统通过界面锚点指纹聚类同一配置面板的历次状态，构建时序状态有向图，自动将 $t_2$ 最终收敛状态提取至主规程，而将 $t_1$ 报错画面归入“常见异常排查附录”，避免通用大模型将作废参数当作正式配置输出。
3. **音画跨模态冲突显式仲裁**：当 Whisper 转录的口述数值（如口头说“超时设为 10 秒”）与对应时间戳画面 OCR 提取的实际输入值（屏幕显示 `15000 ms`）发生数值或量纲冲突时，触发跨模态不一致告警工单。

### 2.3 受控 OpenXML 母版编译与向下兼容布局求解
- 拒绝依赖格式损耗严重的 `Markdown -> Pandoc -> docx` 转换链路；
- 直接以强类型 `DocAST` 驱动底层 OpenXML Transitional 标准（兼容 Office 2007/2010/2016 及政企版 WPS），自动计算页面剩余版心高度、表格列宽自适应分配、跨页断行重复表头（`w:tblHeader`）、高清裁剪图按 DPI 等比限宽嵌入及原生域代码交叉引用，解决工程交付“最后一公里”排版崩坏顽疾。

## 3. 合规准入与物理隔离工程壁垒 (Compliance & Air-Gapped Constraints)

在金融、能源工控、国防科研及审计尽调领域，严苛的运行环境约束构成了纯公有云 SaaS 竞品难以逾越的准入屏障：

1. **零外联物理隔离合规**：严格遵循《数据安全法》与《网络安全等级保护基本要求（等保 2.0 三级）》，支持在完全断网（Air-Gapped）或无外网 VDI 环境中 100% 本地闭环运行，零外部 DNS 解析与零遥测心跳。
2. **终端受限算力与国产信创全栈构建**：
   - 支持在 16GB 内存消费级单卡工作站或国产信创架构（飞腾/鲲鹏 ARM64、龙芯 LoongArch + 银河麒麟/统信 UOS + 昇腾 CANN）上通过 4-bit / 8-bit 量化（GGUF / AWQ / ONNX）稳定运行，全栈依赖保持纯源码可编译性，打包为不可变离线自包含镜像。
